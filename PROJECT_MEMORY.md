# Shipment Tracker — постоянная память проекта

Последнее сверенное состояние: 2026-10-13. Ветка: `main`.

## Назначение
Мобильное веб-приложение для учёта ежедневных отгрузок и ориентировочного расчёта оклада/премиального фонда.

## Ссылки

- Production URL: https://shipment-tracker-wertretwetrertew-4225.vercel.app
- Журнал разработки: [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md)

## Архитектура и данные
- Приложение — статический `index.html`, HTML/CSS/JavaScript без сборщика.
- Данные сохраняются в `localStorage` текущего браузера/устройства.
- Есть экспорт и импорт JSON; облачной синхронизации нет.
- Не использовать реальные пользовательские данные для тестов. После тестирования удалить тестовые записи и проверить возврат исходных значений.
- Перед изменениями проверять текущий код и идентификаторы DOM; не полагаться только на записи в документации.

## Денежные правила — не менять без согласования
- Норма команды: 75 тонн в месяц.
- Премиальный фонд бригады: `max(0, тоннаж − 75) × 85 BYN`.
- Базовый оклад по умолчанию: 1700 BYN, пропорционально фактически отработанным часам относительно нормы месяца.
- Автоматической доплаты за сверхурочные нет.
- Премиальный фонд — общий фонд бригады. Личная доля — предварительная модель и не подтверждена фактическими правилами предприятия.
- Направления отгрузок: Ozon, WB, Другое; вес вводится в килограммах.

## UI и функции
- Основные разделы: Зарплата, Отгрузки, История, Статистика, Настройки.
- На мобильных устройствах навигация располагается сверху и остаётся sticky.
- Форма отгрузки поддерживает создание и редактирование записей.
- Сохранённые значения по месяцам не должны неожиданно перезаписываться глобальными настройками.
