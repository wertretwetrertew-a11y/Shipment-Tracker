# Shipment Tracker

Мобильный веб-прототип для учёта ежедневных отгрузок и расчёта оклада.

## Функции
- Ежедневные записи по направлениям Ozon, WB и «Другое» с весом в килограммах.
- Автоматический пересчёт общего тоннажа, прогресса к норме 75 т и тоннажа сверх нормы.
- Расчёт общего премиального фонда: `max(0, общий тоннаж − 75) × 85 BYN`.
- Отдельная вкладка «Оклад»: 1 700 BYN пропорционально фактически отработанным часам и норме месяца.
- История по месяцам, экспорт и импорт резервной копии JSON.
- Адаптивный интерфейс для телефона и компьютера.

## Запуск
Открой `index.html` в браузере или опубликуй репозиторий через GitHub Pages.

## Хранение и ограничения
Данные хранятся в localStorage браузера на текущем устройстве. Очистка данных браузера или смена устройства может привести к потере истории; для переноса предусмотрен экспорт/импорт JSON. Облачной синхронизации пока нет.

Премия показывается как общий фонд бригады, а не личная премия: правила распределения между сотрудниками неизвестны. Расчёт оклада ограничен базовым окладом, сверхурочные автоматически не увеличивают его.
